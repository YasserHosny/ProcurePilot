# Metrics dictionary

One definition per metric, so reports compare like with like. Platform definitions change; note the platform's
own definition and the export date when reporting.

| Metric | Definition | Source | Channel | Notes |
|---|---|---|---|---|
| Impressions | Times content was shown | Platform analytics | LinkedIn, Facebook, Instagram | Not unique people |
| Reach / unique views | Unique accounts that saw the content | Platform analytics | Facebook, Instagram, LinkedIn (members reached) | |
| Engagements | Reactions + comments + shares/reposts + clicks (+ saves on Instagram) | Platform analytics | Social | State which actions are counted |
| Engagement rate | Engagements ÷ impressions | Derived | Social | Use the same formula across periods |
| Clicks / CTR | Link clicks; CTR = clicks ÷ impressions | Platform analytics | Social, search | |
| Follower growth | Net new followers in the period | Platform analytics | Social | |
| Video views | Platform-defined view (differs by platform) | Platform analytics | Video | Record the platform's threshold |
| Average watch time / completion | Mean seconds watched; % reaching the end | Platform analytics | Video | |
| Organic sessions | Website sessions from organic search or organic social (by UTM) | Website analytics | Website | **No analytics access configured yet** |
| Search impressions / clicks / avg. position | From Search Console | Search Console | SEO | **Not configured yet** |
| Inquiries | Contact form or email inquiries attributable to the period | hello@ inbox count, form events | Website | Form opens the mail app; count received emails, not form opens |
| Pilot access requests | Inquiries with "ProcurePilot pilot access" topic | hello@ inbox | Website | Topic pre-selected by "Request pilot access" |
| Product clicks | Clicks to procurepilot.iron-sys.com | Website analytics / UTM | Website | |

Do not report a metric whose source is not available; write "not measured".
