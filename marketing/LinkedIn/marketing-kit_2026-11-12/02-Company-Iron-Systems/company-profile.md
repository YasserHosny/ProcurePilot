## What Iron Systems does

Four disciplines, one engineering team (S3):

1. **AI solutions**: assistants, document processing and predictions built on the client's own data, evaluated before launch and monitored after.
2. **Custom software**: web platforms, internal tools and APIs designed around the client's process.
3. **Automation**: workflows that handle routine steps and route exceptions to a person, every step visible and open to override.
4. **System integration**: connections between ERP, CRM, accounting and spreadsheets so data moves cleanly.

AI capabilities named on the website (S3): AI assistants, document intelligence, decision support, intelligent
automation, predictive analytics, knowledge search.

Across the stack (S3): backend and APIs, web and mobile, data and machine learning, LLM integration, cloud and
DevOps, quality and security.

## How Iron Systems works (approved principles)

From the website About section (S3), reused on LinkedIn (S5):

- **Problem first.** We understand the work before we choose the technology.
- **AI where it helps.** We test whether a model adds value before we ship it.
- **Built to last.** Clean, documented code your team can own.

Delivery process, six stages (S3): Understand → Architect → Build → Validate → Launch → Improve, each with a named
client deliverable (problem brief, architecture and delivery plan, working software every cycle, evidence that it
works, a live monitored system, continued improvement).
