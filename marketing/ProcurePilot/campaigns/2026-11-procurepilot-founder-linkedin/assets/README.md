# Assets

- `drafts/`: work in progress.
- `in-review/`: waiting for `campaign-review` and the owner.
- `approved/`: approved (G-asset), ready for a publish-ready package. **Not published.**

File names: `<channel>-<format>-<slug>-<lang>-v<N>.<ext>`, e.g. `linkedin-carousel-landed-cost-en-v2.pdf`.
Never overwrite an approved version; add `v<N+1>`.
