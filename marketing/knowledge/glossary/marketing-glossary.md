## Marketing OS terms

| Term | Meaning here |
|---|---|
| Marketing OS | This folder (`marketing/` in the ProcurePilot repo): knowledge, workflows, skills, templates and checks |
| Upstream skill | A skill copied unchanged from `coreyhaines31/marketingskills` (see `config/upstream-skills.yaml`) |
| Custom skill | One of the four Iron Systems skills: marketing-orchestrator, product-discovery, campaign-operations, campaign-review |
| Shared context file | `.agents/product-marketing.md`, read first by every upstream skill; derived from `knowledge/` |
| Evidence labels | V verified · I interpretation · H hypothesis · ? unknown |
| Approval gate | A point where a named human must approve before work continues (`config/workflow-rules.yaml`) |
| Publish-ready | Reviewed and approved, sitting in `assets/approved/`; still **not** published |
| Organic | Owned and earned channels (website, SEO, LinkedIn, Facebook, Instagram, video). No paid media |

## Marketing terms

| Term | Meaning |
|---|---|
| ICP | Ideal customer profile: the company type that gets most value |
| Persona | A role inside the buying group (user, champion, decision maker, financial buyer, technical influencer) |
| JTBD | Jobs to be done: the progress a buyer is trying to make |
| Positioning | Who it is for, the alternative it beats, why, and the proof |
| Messaging matrix | Messages mapped to personas, stages and proof |
| Proof point | Evidence that supports a claim (screen, document, data, permissioned quote) |
| Content pillar | A recurring theme content is organised around |
| Search intent | What a searcher wants: informational, commercial, transactional, navigational |
| CTA | Call to action |
| CTR | Click-through rate |
| Engagement rate | Engagements ÷ impressions, as defined per platform in `analytics/metrics-dictionary.md` |
| AEO / GEO | Optimising to be cited in AI-generated answers |
| CRO | Conversion rate optimisation |
| UTM | Tracking parameters on links (`utm_source`, `utm_medium`, `utm_campaign`) |
