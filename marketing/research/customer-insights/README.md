# Customer insights

Anonymised notes from real customer evidence: pilot conversations, inquiries, support themes, survey results.

- Remove names, emails, phone numbers and company names unless the person agreed to be quoted; record where consent is kept.
- One file per source batch: `YYYY-MM-DD-<source>.md` with method, sample, verbatim quotes and the synthesis.
- Upstream skill: `customer-research`. Promote findings into `knowledge/` only with a link back to the file here.
