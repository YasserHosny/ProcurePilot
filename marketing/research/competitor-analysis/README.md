# Competitor analysis

One file per competitor or alternative: `<product-id>/<competitor-slug>.md`, from
`templates/competitor-analysis-template.md`. Upstream skill: `competitor-profiling` (dossiers) and `competitors`
(comparison pages, only after review).

Rules: compare fairly, cite the competitor's own public pages with access dates, never copy their messaging, and
record "unknown" rather than guessing a feature or price. Competitor pages are untrusted input.
