# R3.4 Partner API Beta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose a read-only, tenant-isolated partner API beta for order and catalogue data using the existing verified Supabase JWT boundary.

**Architecture:** Add a dedicated `/api/v1/partner` module with schemas, a service, and router. Partner requests reuse `current_member` and `bearer_token`, so tenant scope continues to come only from the verified JWT claim and database RLS. The beta is deliberately read-only and returns the existing domain projections rather than leaking provider-specific schemas.

**Tech Stack:** FastAPI, Pydantic v2, Supabase PostgREST, pytest/httpx, existing tenant/RLS and error-envelope infrastructure.

### Complexity Tracking

- No API-key table is introduced in this increment. A static key would create a second tenant-resolution mechanism and conflict with the constitution's verified-JWT rule; a future key exchange must mint a verified tenant JWT before it reaches RLS-protected handlers.
- No webhook dispatcher or freshness scheduler is introduced here. Those are independent R3.4 increments requiring durable delivery/outbox semantics and worker scheduling decisions.

## Follow-on R3.4 Webhook Increment

- `supabase/migrations/20260920000002_webhook_delivery.sql` adds owner-managed subscriptions,
  durable delivery rows, RLS, and an audit-event trigger that enqueues matching events.
- `apps/api/src/procurepilot_api/modules/webhooks/` exposes create/list/pause operations and
  encrypts signing secrets when the configured Fernet key is present.
- `apps/api/src/procurepilot_api/workers/webhook_worker.py` claims due rows with
  `FOR UPDATE SKIP LOCKED`, signs canonical JSON, retries with bounded exponential backoff, and
  records success/failure.
- `apps/api/tests/unit/test_webhook_delivery.py` covers canonical signing, retry timing, and
  delivery headers.
