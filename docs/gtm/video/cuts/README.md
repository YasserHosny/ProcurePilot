# Demo video cuts

Every rendered version of the «مطاعم سند» demo video, newest first. Each version has four cuts: Arabic and English, 16:9 (YouTube, LinkedIn, website) and 9:16 (Reels, TikTok, Shorts, WhatsApp status), named `procurepilot-demo-{ar,en}-{16x9,9x16-60s}.mp4`. Up to v2.2 the app screens are Arabic in every cut and the English cuts only translate the captions; the v2.2 English-UI cuts show the English interface.
