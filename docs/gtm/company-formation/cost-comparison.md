# مقارنة التكلفة على 3 سنين: مصر ولا أمريكا ولا الإمارات لـ ProcurePilot

**التاريخ:** 17 أكتوبر 2026
**مرتبط بـ:** [`recommendations.md`](recommendations.md)، [`egypt-company-setup-guide.md`](egypt-company-setup-guide.md)

> **تنبيه:** دي **تقديرات للمقارنة** مش عروض أسعار. الأرقام الرسمية متعلّم عليها وليها مصدر، والباقي من تجارب أعضاء الجروب أو تقديرات مني (مكتوب جنبها «تقدير»). اتأكد من أي رقم قبل ما تبني عليه قرار. **مفيش ضرايب مصرية محسوبة على الخيارات الأجنبية**، لأن معاملتها لسه سؤال مفتوح للمحاسب، وده لوحده سبب إنها ممكن تبقى أغلى بكتير من الجدول.

---

## 1. الافتراضات

- **السعر:** 1,500 جنيه للفرع في الشهر (D-2 في خطة الـ GTM)، والعملاء بيدفعوا **بالجنيه**.
- **3 سيناريوهات إيراد سنوي:**
  - **A:** 10 عملاء × 5 فروع = **900 ألف جنيه**
  - **B:** 30 × 5 = **2.7 مليون جنيه**
  - **C:** 100 × 5 = **9 مليون جنيه**
- **هامش ربح قبل الضرايب 40%** (تقدير)، علشان المقارنة مع الأنظمة اللي بتحاسب على الربح.
- **سعر الدولار للتقريب: 50 جنيه** (تقدير، غيّره حسب سعر اليوم).

## 2. أولاً، ملاحظة حاسمة قبل الأرقام

لأن **عملاء ProcurePilot مصريين وبيدفعوا بالجنيه وعايزين فاتورة إلكترونية مصرية**، أي خيار أجنبي **هيحتاج كمان كيان مصري** يستقبل الفلوس ويصدر الفواتير:
- Ahmed Ali (LLCGATE) قال ده صراحة.
- والبوابات المصرية بتسوّي بالجنيه بس، فالشركة الأجنبية مش هتقدر تستقبل من بوابة مصرية.

يعني الخيارات الأجنبية مش **بديل** للشركة المصرية، **هي تكلفة فوقها**.

## 3. تكلفة كل خيار (3 سنين)

### الخيار 1: شركة الشخص الواحد في مصر + النظام المبسط ✅

| البند | السنة 1 | السنة 2 | السنة 3 | المصدر |
|---|---|---|---|---|
| التأسيس | 15,000 | — | — | الجروب: 10–20 ألف |
| المحاسب (فواتير + إقرارات) | 19,000 | 19,000 | 19,000 | الجروب: 1,000 شهرياً + 7,000 سنوياً |
| ضريبة مبسطة (A / B / C) | 4,500 / 20,250 / 90,000 | نفسها | نفسها | قانون 6/2025، اتأكدت منها |
| ضريبة توزيع الأرباح | **معفاة** في النظام المبسط | | | EY |
| **الإجمالي على 3 سنين (A)** | **حوالي 85,500 جنيه** | | | |
| **الإجمالي على 3 سنين (B)** | **حوالي 132,750 جنيه** | | | |
| **الإجمالي على 3 سنين (C)** | **حوالي 342,000 جنيه** | | | |

> الـ VAT 14% بتتحصّل من العميل وبتتورّد، وعميلك B2B بيخصمها، فمش تكلفة عليك. والتأمينات مش محسوبة.

### الخيار 2: شركة مصرية بالنظام العادي (لو ما اتقبلتش في المبسط)

| | A | B | C |
|---|---|---|---|
| ضريبة 22.5% على ربح 40% | 81,000/سنة | 243,000/سنة | 810,000/سنة |
| + المحاسب | 19,000/سنة | 19,000/سنة | 19,000/سنة |
| **3 سنين (+ تأسيس 15,000)** | **حوالي 315,000** | **حوالي 801,000** | **حوالي 2,502,000** |

> ده بيبيّن قيمة النظام المبسط. وبيبيّن أهمية تأكيد إن نشاطك مش «استشارات مهنية بـ 90% من عميل أو اتنين»، لأن ده الاستثناء الوحيد اللي ممكن يخرجك منه.

### الخيار 3: US Wyoming LLC **فوق** الشركة المصرية

| البند | سنوياً | المصدر |
|---|---|---|
| التأسيس (مرة واحدة) | حوالي 250$ | الجروب (بنفسك 200–250$) |
| Annual report للولاية | **60$** | [Wyoming، الحد الأدنى](https://nolo.com/legal-encyclopedia/annual-report-tax-filing-requirements-wyoming-llcs.html) |
| Registered agent | 25–125$ | الجروب |
| عنوان بريدي أمريكي | حوالي 228$ (19$/شهر) | الجروب |
| إعداد Form 5472 + Pro-forma 1120 | 200–400$ | الجروب |
| **الإجمالي السنوي** | **حوالي 500–800$ = 25–40 ألف جنيه** | |
| **3 سنين** | **حوالي 80–125 ألف جنيه، فوق الخيار 1** | |
| ⚠️ مخاطرة | غرامة **25,000$ لكل Form 5472** فايت، و25,000$ إضافية كل 90 يوم بعد إخطار IRS | [Form 5472 guide](https://www.sdocpa.com/form-5472-foreign-owned-business-filing/) |
| ⚠️ ضرايب مصر | المقيم في مصر بيتحاسب على **دخله من كل العالم**، فأرباح الـ LLC غالباً خاضعة في مصر | [PwC](https://taxsummaries.pwc.com/egypt/individual/taxes-on-personal-income) |

### الخيار 5: منطقة حرة في الإمارات **فوق** الشركة المصرية

| البند | سنوياً | المصدر |
|---|---|---|
| رخصة من غير إقامة (الإمارات الشمالية) | حوالي 5,500 درهم | الجروب |

| **الإجمالي (من غير إقامة)** | **حوالي 75 ألف جنيه في السنة** (تقدير، بحساب الدرهم بحوالي 13.6 جنيه) | |
| **3 سنين** | **حوالي 225 ألف جنيه، فوق الخيار 1** | |

## 4. الملخص

| الخيار | تكلفة 3 سنين (سيناريو B: 2.7 مليون في السنة) | بيحل مشكلة عندك؟ |
|---|---|---|
| **1. مصر، النظام المبسط** | **حوالي 133 ألف جنيه** | ✅ فاتورة إلكترونية، تحصيل بالجنيه، توظيف قانوني، Apple/Google كشركة |
| 2. مصر، النظام العادي | حوالي 801 ألف جنيه | ✅ نفس المزايا، بتكلفة أعلى بكتير |
| 3. + US LLC | 133 ألف + 80–125 ألف + ضرايب مصرية محتملة | ❌ مفيش مشكلة بيحلها دلوقتي |
| 4. + Delaware C-Corp | 133 ألف + 230–300 ألف | ⏳ مفيدة **بس** وقت جولة تمويل |
| 5. + الإمارات | 133 ألف + حوالي 225 ألف | ⏳ مفيدة **بس** لو عميل خليجي طلب كيان محلي |

**النتيجة:** الخيار 1 أرخص بفرق كبير، وهو الوحيد اللي بيحل احتياجات ProcurePilot الفعلية دلوقتي. أي خيار تاني تكلفة إضافية مستنية محفز (مستثمر أو عميل خليجي) يبررها.
